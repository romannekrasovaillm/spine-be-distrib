# arch-be (Spine Banking Edition) — старт за 5 минут

Это доменный агент-харнесс solution-архитектора: один статический бинарь
для Linux x86-64 (зависимостей нет). Платформы: **Linux** — нативно;
**Windows** — только через WSL2 (Ubuntu, внутри всё работает дословно по
инструкции); **macOS** — нативной сборки нет: харнесс ставится на
Linux-машину/VM (на самом Маке — UTM/Parallels с Ubuntu, на Apple Silicon
с Rosetta), а inference-сервер локальной модели может жить и на самом
Маке (Ollama, llama.cpp, LM Studio — Metal). Работает с китайскими LLM
(DeepSeek / Z.AI GLM / Kimi — прямой доступ из РФ) и с локальными
моделями в контуре банка (llama.cpp / vLLM / Ollama, в т.ч. веса с
HuggingFace).

## Проверка целостности (обязательно)

```bash
sha256sum -c SHA256SUMS.txt        # обе строки должны ответить «OK»
```

## Быстрый старт

```bash
cp arch-be-linux-x86_64 ~/.local/bin/arch-be && chmod +x ~/.local/bin/arch-be
arch-be init                         # конфиг + ассеты в ~/.arch-harness
export DEEPSEEK_API_KEY="sk-..."     # ваш ЛИЧНЫЙ ключ: platform.deepseek.com
arch-be run -q "Привет! Кто ты?"     # проверка; дальше: arch-be (TUI)
```

Ключ GLM (z.ai) или Kimi (kimi.com) вместо DeepSeek? `export ZHIPU_API_KEY`
/ `KIMI_API_KEY` и одна строка `default_model = "glm"` (или `"kimi"`) в
`~/.config/arch-harness/config.toml`. Бесплатный старт без банковской
карты: регистрация на z.ai по email (карта не нужна, пока пользуетесь
бесплатными flash-моделями) → `export ZHIPU_API_KEY` →
`default_model = "glm-flash"` — сценарий проверен живьём 2026-09-08.

Полная инструкция — `deploy-kit/ИНСТРУКЦИЯ_ЧЕЛОВЕК.md`
(установка, все модели, локальные LLM с HuggingFace, контекстные папки,
таблица граблей). Протокол тестирования — `deploy-kit/ПРОВЕРКА.md`.

Диаграммы Archify: инструменты в бинаре, движок — в tarball'е релиза
`archify-vendored-2.17.0-dev.1.tar.gz` (закреплённая версия; из сети через
npx не ставьте — там непроверенный latest). Нужен Node.js >= 18:
`tar xzf archify-vendored-*.tar.gz -C ~/.arch-harness/` + абсолютный путь
в `[archify].cli_path` конфига — подробности в инструкции, шаг 6.

## Если настраивать будет ваш ИИ-агент

Передайте ему этот каталог целиком и скажите:
«Действуй по `deploy-kit/ИНСТРУКЦИЯ_АГЕНТ.md`, шаг за шагом, с приёмочными
проверками. Ключи спроси у меня». Агент сам установит бинарь, выполнит
init, doctor и приёмочные прогоны по выбранным провайдерам.

## Правила гигиены (важно в банке)

- **Ключи — личные.** Не пересылайте свой ключ коллеге: у каждого свой
  аккаунт провайдера (расходы и лимиты привязаны к ключу). Значения
  ключей не пишутся в конфиг, чаты и файлы — только env/файлы ключей.
- Закрытый контур без интернета: локальная модель (инструкция, раздел
  HuggingFace) + `web.enabled = false` в конфиге.
- Версия комплекта: v0.1.5 (2026-09-09). Обновления — новыми архивами;
  проверяйте SHA-256 каждый раз.
